# Hungry Dragon Store Coin / Gift Card

Store Coin / Gift Card may be used as an extra use of **Heroic Inspiration**. Limit to one coin per player, per session.

Like Heroic Inspiration, Store Coins may not be traded or given to other players.

!!! cite "Reference"
    See the *Player's Handbook 5.5e* → Rules Glossary for more information on Heroic Inspiration.
