# The Hungry Frontier — Rules & Mechanics

*Probably not a mimic.*

## Purpose and Overview

As the Guides of the Hungry Frontier, we put forth this living document (probably not a mimic) to put into writing the rules, policies and guidelines that are to be used in the operation of the Hungry Frontier.

This document is to be kept up-to-date with the currently used Ruleset, House Rules, and Rules/Mechanics decisions used by the Hungry Frontier, its Guides and Players.

Any establishment of House/Table Rules, changes to the codified Official game rules or changes to the codified House/Table Rules will be listed in the following pages.

Any changes to the document will be made on a new line and have the date of the change saved at the end of the change, with any obsolete info being struck out, not deleted.

We reserve the rights to change these rules whenever.
