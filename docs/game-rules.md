# Game Rules

Below are the official free basic rules published by Wizards of the Coast for both 5e and 5.5e.

## D&D 5e Basic Rules PDF

:material-file-pdf-box: [D&D 5e Basic Rules PDF](https://drive.google.com/file/d/1895dy_YO_0RLW1-2OhmHv2S4eZJWwFzm/view?usp=drivesdk)

!!! note "No printable 5.5e Basic Rules"
    WotC D&D 5.5e does not have a printable Basic Rules Document, and can only be found on D&D Beyond, see links below.
